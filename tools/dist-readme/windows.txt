E-Rect for Windows (x86-64)
===========================

Run erect.exe. Keep the packs folder next to it - that is where the music and
sound effects live. Without it the game still runs, just silently.

It needs nothing installed: the C runtime is linked into the executable, and
everything else it uses is part of Windows itself. It is not signed, so
SmartScreen may ask before the first launch - choose More info, then Run anyway.

Controls
--------
              player 1      player 2      gamepad
    move      A  D          LEFT  RIGHT   d-pad or left stick
    jump      W             UP            A (bottom button)
    attack    SPACE         ENTER         X (left button)
    dash      LEFT SHIFT    RIGHT SHIFT   either shoulder button
    slam      S             DOWN          B (right button) or down
    pause     ESC                         START

Each player picks a keyboard half or a gamepad in Settings. Menus answer to any
keyboard and any pad.

These are the layouts the game ships with. SETTINGS > CONTROLS moves any of the
six game actions to other keys or buttons, up to three for each, and one key may
serve several actions. Pause and the menus keep the keys above.

Settings and high scores go to %APPDATA%\erect\settings.json
