E-Rect for PSP
==============

Install
-------
Copy everything in this archive to the root of your Memory Stick. Nothing has to
be arranged by hand - the folders are already in the shape the PSP expects, and
this file travels with the game rather than landing among your own:

    ms0:/PSP/GAME/ERECT/EBOOT.PBP
    ms0:/PSP/GAME/ERECT/README.txt
    ms0:/PSP/GAME/ERECT/pack/pack1/*.wav
    ms0:/PSP/GAME/ERECT/pack/pack2/*.wav
    ms0:/PSP/GAME/ERECT/pack/pack3/*.wav

Then start it from the PSP's Game menu (Memory Stick).

On a PSP Go the same folders work on internal storage as well
(ef0:/PSP/GAME/ERECT/...). The game looks for its music and settings beside its
own EBOOT, wherever that is, so the folder can also be renamed.

Homebrew needs custom firmware. On stock firmware the EBOOT will not launch.
Runs on a PSP Go with custom firmware, and in PPSSPP 1.20.4.

Soundtracks
-----------
Three soundtracks ship and one is drawn at random every time you reach the menu
and every time you start a run, so a session moves between them. They are held
in memory together, which is what makes the change instant instead of a pause
while six megabytes are re-read.

Loading them takes a few seconds; a counter shows the progress. If a pack is
missing, or memory is short for all three, the game plays with as many as it
could load. With none at all it runs silent, and the title screen says why
along the bottom - so if it is quiet, look there first.

Controls
--------
    D-pad / analog nub   move
    Cross / L            jump
    Square               attack
    Triangle / R         dash
    Circle / Down        slam
    Start                pause menu
    Home                 quit

These are the buttons the game ships with. SETTINGS > CONTROLS moves any of the
six game actions to other buttons or the nub, up to three for each, and one
button may serve several actions. Start and the menus keep the buttons above.

One player: a PSP has one controller, so the 2 PLAYERS mode is not offered.

Saves
-----
Settings, high scores, the controls and which HEAD STARTs are unlocked are
written to settings.dat beside the EBOOT. How far each weapon run got is shown
for the current session only; it is not kept between launches on the PSP.
