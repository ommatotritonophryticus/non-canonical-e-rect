E-Rect for Linux (x86_64)
=========================

Run ./erect. Keep the packs folder next to it - that is where the music and
sound effects live. Without it the game still runs, just silently.

Requirements
------------
Built on Ubuntu 24.04, so it needs glibc 2.39 or newer: Ubuntu 24.04, Debian 13,
Fedora 40 or anything later. It links against the system ALSA and udev
libraries; on most desktops these are already present. If not:

    Ubuntu 24.04+   sudo apt install libasound2t64 libudev1
    Debian          sudo apt install libasound2t64 libudev1
    Fedora          sudo dnf install alsa-lib systemd-libs
    Arch            already present in base

X11 and OpenGL are loaded at runtime. Under Wayland it runs through Xwayland.

Controls
--------
              player 1      player 2      gamepad
    move      A  D          LEFT  RIGHT   d-pad or left stick
    jump      W             UP            A (bottom button)
    attack    SPACE         ENTER         X (left button)
    dash      LEFT SHIFT    RIGHT SHIFT   either shoulder button
    slam      S             DOWN          B (right button) or down
    pause     ESC                         START

Each player picks a keyboard half or a gamepad in Settings. Menus answer to any
keyboard and any pad.

Settings and high scores go to ~/.config/erect/settings.json
